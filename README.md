## ⚡ Quick Start

```bash
# 1. Install & start Backend (Port 5001)
cd backend
npm install
node server.js

# 2. In another terminal, install & start Frontend (Port 3000)
cd frontend
npm install
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.
